# 星球识字仓：产品功能规划

## 文档定位与当前状态

本文件描述面向 5 岁儿童的识字网页产品目标。截图中的栏目是需求来源，不代表这些功能已完整实现。仓库已有 Vite、React、TypeScript 和 Adobe React Spectrum 项目，字库已从 18 个示例扩充为 600 个唯一常用字，具备词境拼音、例词、短句、三组分级、搜索、分页和主题三字换组。完整游戏流程、正式学习记录与复习机制、真实录音和规范笔顺素材仍属于规划目标；目前的字词校验不代表教师专业审校。

产品方向建议为：以平板触控为主、无需登录、默认仅在本机保存学习数据。首期先验证一小组内容与四种识字玩法，再逐步补足字库和素材。当前工程配置 React 19.3.0、TypeScript 7.0.2 与 Adobe React Spectrum 3.47.5。

## 产品目标与设计边界

- 让孩子在短时、可重复、轻松的活动中认识常见汉字，并把单字连接到熟悉的图像、声音和词语。
- 一次安排 3–5 个新字，单次活动约 5–8 分钟。时间是家长和产品的建议尺度，不显示倒计时、不自动结束孩子正在做的步骤，也不限制孩子继续或提前离开。
- 不把速度、答题量或连续打卡作为能力评价。答错可听、看提示或再试，不扣分、不清空进度、不使用“失败”惩罚语。
- 产品不诊断儿童的识字能力。成长数据只描述本机可观察到的练习和复习情况。
- 600 个常用字已可浏览，是作者整理的可选素材池。教育部没有规定幼儿园统一必认字表或识字数量；初识、进阶、继续探索各 200 字属于产品分级，孩子无需全部学完。官方依据见 [学前识字依据](学前识字依据.md)。图像、正式录音与笔顺按资源准备情况逐步补齐。

## 信息架构

首页是“星际探索舱”，以星图作为导航背景，六个主题入口可直接进入相应字卡或探索活动。星球是视觉包装；科学事实和字词用简短、年龄适宜的表达呈现。

| 一级入口 | 主要内容 |
| --- | --- |
| 识字乐园 | 认识汉字、看图识字、听音选字、翻卡配对；可选择主题、继续上次活动或抽取待复习卡片 |
| 词语闯关 | 用已接触的汉字组成常见双字词和短语；关卡按孩子已见内容渐进，不因未解锁而阻断自由练习 |
| 写字练习 | 看字形、听读音、观察笔顺示范并沿笔画描写；按素材完成度逐步开放 |
| 汉字宇宙（600字） | 已支持查看字、词境拼音、例词和短句，按分级和主题筛选，按字、词或拼音搜索；图片、真实音频、笔顺与学习状态后续补齐 |
| 我的汉字卡 | 查看已收集、正在练习、待复习和已熟悉的字卡；支持按主题、熟悉程度浏览 |
| 成长足迹 | 以主题星图、卡片收藏和温和的近期活动回顾呈现过程，不提供班级、好友或全站排行 |
| 给爸爸妈妈 | 家长设置、进度说明、数据导出与清除、素材和版本说明；设置儿童误触保护 |

全局导航保留“回家”“再听一次”“需要提示”“先休息”等清晰入口。孩子离开一个玩法后回到星图，进度在当前设备内保存；没有账号登录或社交功能的前提下，不显示头像排行、他人进度或在线挑战。

## 5 岁内容原则与六个探索主题

内容以孩子熟悉的事物和清楚的图像为入口。每张卡片优先突出一个目标字，并提供规范读音、简短释义、一个常见词和一幅准确图示。生字、拼音、部件等信息分层显示，默认不在一屏堆叠大量文字。生字出现时允许语音重播、图像提示和重复操作。

下表是首批主题内容的候选映射，不等同于已经制作的字卡。场景可复用已学字；每次实际引入的新字仍控制在 3–5 个。发布前逐条复核简体字、读音、词义、配图和科学描述；有多音字时按词语上下文标注读音。

| 探索主题 | 候选目标字与常见词语 | 面向孩子的事实表达与内容边界 |
| --- | --- | --- |
| 太阳 | 日（太阳、日光）、光（阳光）、明（明亮）、白（白天）、天（天空） | 太阳是一颗恒星，会发光发热。用“白天能看到阳光”等生活经验连接字词；不把太阳说成行星。 |
| 月亮 | 月（月亮、月光）、夜（夜空）、圆（圆月）、亮（明亮）、云（云朵） | 月亮看起来会有圆缺变化；月亮本身不会像太阳那样发光，我们看到的月光主要是太阳光照到月球后反射来的。首期给孩子的表达可以简化为“月亮借来太阳的光”，成人说明保留完整意思。 |
| 地球 | 地（地面）、球（地球）、水（水）、山（高山）、家（家园） | 地球是我们生活的行星，有陆地和海洋，也有适合许多生物生活的环境；不要暗示地球只有水或只有人类居住。 |
| 火星 | 火（火星）、红（红色）、石（石头）、土（土地）、沙（沙尘） | 火星看起来偏红，与表面含铁尘土有关；“火星”是名称，不表示星球正在燃烧。提到表面时使用岩石、尘土等准确图像，不用熔岩火海作为常态场景。 |
| 土星 | 土（土星、泥土）、环（土星光环）、冰（冰块）、大（大小）、气（空气） | 土星周围可见由冰和岩石碎块等组成的光环；土星是气态巨行星，不能画成孩子能站在云面上的坚硬地面。词语“土星光环”用于理解，不要求一次学会每个字。 |
| 银河 | 复用星（星星）、光（星光）、天（天空）、夜（夜空）；兴趣词：银河、星系 | 银河不是天空中的液体河流，而是我们所在星系在夜空中的带状外观。该场景以观赏、听读和复用熟悉字为主；“银河”“星系”等词可作为兴趣标签或家长陪读内容，不强制识记“银”“系”，不纳入该主题的必学考核。 |

主题活动不得让孩子把插画误认作实景照片。图像、短文、配音和词语应由内容审核人按主题事实清单复核；不确定的事实先不进入教学卡片。

## 玩法流程与状态

**共用开始流程：** 选择主题或“接着玩” → 展示本次少量目标字 → 选择一种玩法 → 完成后收集字卡并显示温和反馈 → 选择“再玩一会儿”“复习几张”或“回星图”。孩子可随时退出；系统只记录确实发生的接触和作答，不把退出视为失败。

| 玩法 | 一次活动流程 | 结果与异常状态 |
| --- | --- | --- |
| 认识汉字 | 展示大字、主题插图和读音；可播放目标字与例词；轻触翻看简短提示或切换下一张 | “听一听”“再看一次”“我认识它/还想再练”都可选；跳过不改熟悉等级 |
| 看图识字 | 展示一张清楚的物品或场景图，提供 2–3 个字或词供触选；作答后显示目标字、读音和例词 | 答对给出具体肯定；答错提供图像或读音提示，可重选、跳过或看答案。选项顺序不暗示速度 |
| 听音选字 | 孩子主动播放读音或例词，在 2–3 个视觉区分清楚的选项中选择；可不限次数重听 | 使用没有歧义的词语和上下文，避免把多音字单独作为无提示音频题；音频缺失时不开放该题，显示可继续的图文活动 |
| 翻卡配对 | 翻开少量卡片，将目标字与对应插图或词语配对；新手局面建议 2 对，熟悉后最多 3 对 | 配对失败不扣分，卡片平缓合上并可显示提示；允许查看答案，不因完成时间或连续错误惩罚 |
| 词语闯关 | 从熟悉字组成词语；先图词配对，再从有限选项拼合；关卡只引入少量未知字并提供读音 | 不要求孩子已掌握才可进入后续自由探索。未识别的字给解释和复习入口，关卡状态不会阻止其他玩法 |
| 写字练习 | 先看标准字形和逐笔演示，再用手指或触控笔描写；提供重来、放大和跳过 | 描写是练习记录，不用未经验证的自动评分判定“写错”。无法识别触控或笔画素材未就绪时，可继续观察笔顺或退出 |

关键状态包括：未接触、初次认识、练习中、待复习、较熟悉；玩法内另有准备中、播放中、已作答、提示中、已完成、可退出等状态。所有状态都提供明确可触控的操作，不依赖拖拽、快速反应或颜色变化才能继续。

## 字库、去重与掌握标准

当前有 600 个唯一简体汉字条目，维护清单与三组内容分别存放在 scripts/*-characters.txt 与 src/content/。字形作为稳定 ID，不把词语、拼音、主题副本或同一字的多种用法重复计数。自动校验包括清单覆盖、去重、例词包含目标字、例句包含例词及词境读音。多音字和轻声按当前例词读音显示；朗读例词与例句，避免脱离词境单独朗读造成读音冲突。一个字目前只有一个主主题，后续可关联多个主题，仍保持唯一主条目。正式素材按审核完成度开放相应玩法。

建议的字卡元数据：稳定字 ID、规范字形、拼音及声调、词语级读音、儿童版释义、例词、主题 ID、提示图、音频资源 ID、笔顺资源 ID、内容审核状态和来源说明。资源可处于“待制作/可用/需复核”状态；界面按状态决定是否提供相应玩法。

“掌握”是产品内可解释的复习状态，不作为儿童能力结论。建议状态推进如下：

- **初次认识：** 进入主题并看过目标卡片。单纯展示不计作答正确。
- **练习中：** 有过主动选择、配对或描写。记录使用的玩法、是否看提示和结果。
- **待复习：** 根据上次接触时间提示再次回看，不通过推送催促。
- **较熟悉：** 至少在两个不同日期、两种不同玩法中累计有 3 次无提示正确辨认；最近一次复习也正确。该门槛可配置并需根据首期观察调整，不能对外宣传为科学测评。

复习计划可从首次学习后的第 1、3、7、14、30 天提供复习建议；每次无提示答对后推进到下一间隔。答错、看提示或主动选择“还想再练”时，安排一次温和提示并把该字留在较短复习间隔，避免在同一场次反复纠错。孩子错过计划日期不丢进度、不积累欠练惩罚；首页只展示少量可选的“来看看这些字”。

## 奖励、足迹与家长区

奖励采用可收集的星星贴纸、星球装饰和星图点亮等形式，鼓励探索、重复练习和主动休息。奖励不与答题速度、单日数量、连续天数或他人表现绑定；没有排行榜、公开分享、失败扣星或错过打卡清零。默认不出现付费诱导或商业广告。

成长足迹显示已经遇见的字、最近练过的主题和复习建议，可以按周或主题浏览。将“尚在练习”与“较熟悉”说清楚，不显示百分制能力分或误导性准确率结论。孩子使用的反馈短而具体，例如“你又认出了‘月’字”或“想听声音也可以”。

家长区建议包含：

- 音量、配音开关、动画强度、文字/拼音辅助、主题内容说明和单次建议时长；不强迫孩子完成时长。
- 按字或主题查看练习记录、状态定义及最后接触日期，并解释这些记录不是测评。
- 将学习数据导出为带版本号的 JSON 文件；提供数据格式说明。阶段 2 可加入校验后导入、合并/替换预览和重复数据处理；导入不得无提示覆盖现有进度。
- 清除本机全部学习数据、恢复默认设置和查看当前内容包版本；清除前明确说明影响并要求成人再次确认。
- 儿童误触保护可用按住入口或成人操作题。它只是避免误入的交互保护，不应宣称为身份验证或安全锁。

## 本地优先数据与工程边界

首期建议不接后端、不要求账号、不发送行为分析数据。教学内容作为带版本号的静态资源随应用发布；学习事件和进度保存在浏览器 IndexedDB，少量界面偏好可放在 localStorage。通过仓储接口隔离页面与持久化实现，便于后续升级数据库格式；所有界面从同一字卡 ID 读取内容，不能按活动各复制一套汉字。

建议数据实体：`Character`（唯一字、主题关联与资源引用）、`Word`（词形、词级读音、释义及组成字 ID）、`LearningEvent`（时间、字符 ID、活动类型、是否提示、结果）、`CharacterProgress`（当前阶段、最近复习日、下次建议日、熟悉度计数）、`Settings`（家长偏好），以及 `schemaVersion` 和 `contentVersion`。学习记录只保存完成复习所需的最少信息，不要求姓名、生日或精确位置。

导出文件包含格式版本、内容版本、导出日期和本机学习数据。导入前校验结构、字段和版本；无法安全迁移时说明原因并保留原数据。IndexedDB 不可用、空间写入失败或数据损坏时，要明确告知学习记录可能无法保存，提供重试或数据导出入口；不显示虚假的“已保存”。无网络时，已经随包提供的活动和声音仍可使用。

## 响应式、无障碍与交互要求

- 以平板横竖屏触控布局为基准，同时支持窄屏手机和桌面浏览器；内容卡在窄屏单列排列，在宽屏扩大留白，不缩小主要触控目标。
- 主要按钮建议至少 48×48 CSS 像素，间距充足；不把悬停、精细拖拽、双指手势或摇晃设备作为唯一路径。
- 用清晰的文字标签、语音和图形共同表达信息；颜色不作为正确/错误或状态的唯一提示。支持键盘焦点、语义化按钮、读屏标签和合理焦点顺序。
- 正文和关键状态保持足够对比度，字形清楚；读音可由用户主动播放、重复播放或关闭。动画尊重系统减少动态效果设置，不用闪烁和突然位移表达结果。
- 页面缩放不破坏布局；弹层能用明确按钮关闭，错误和离线状态说明可执行的下一步。

## 内容资产与交付阶段

音频和笔顺是内容质量的一部分，不能用占位音、自动合成结果或不确定的动画冒充已审校资产。音频需由普通话母语审校，检查字音、词语语境、音量和剪辑；笔顺资料按可靠的规范书写来源制作、逐字复核。图示应与事实一致并有文字替代说明。

**MVP：** 保留现有首页、六个主题与 600 字浏览能力；先为一个小型试用字集（建议约 30 个唯一常用字，按内容审校结果调整）制作经审核的图像和录音，覆盖认识汉字、看图识字、听音选字、翻卡配对；实现汉字卡、基础复习排程、轻量足迹、家长设置和本地数据导出。不足的音频题隐藏或替换成图文活动。词语、写字页面保留规划入口，此阶段不要求补齐全部 600 字的游戏素材。

**阶段 2：** 扩充并去重字库；实现词语练习、触控描写，补齐复习调整策略、经审校的普通话音频、规范笔顺动画和导入/合并流程；根据实际使用调整主题分配、选项数和成人设置。只有准确笔顺数据通过审核后才开放逐笔指导。按资源完整度逐批开放，而非用空白题占位。

**阶段 3：** 补齐现有 600 字的专业内容审校、图像、真实音频与适用笔顺素材；增加更多主题内容、离线内容包升级和本机数据迁移体验。若未来考虑跨设备同步、账号或家长远程查看，须另行评估并明确数据与隐私方案；这些不属于当前无后端规划的既有能力。

## 验收标准

- 首页能到达截图所列的七类入口：识字乐园（含四种玩法）、词语闯关、写字练习、600 字库、我的汉字卡、成长足迹和给爸爸妈妈。
- 任一学习流程一次最多引入 3–5 个新字，常规单次活动按 5–8 分钟设计；全程无倒计时、答错惩罚和漏练清零。
- 六个主题均有明确的字词映射和事实边界；银河场景不会强制教学“星系”等晦涩目标字；主题重复字不会被算作新字。
- 字库统计基于唯一且审核通过的规范字条目；未达 600 时清楚显示实际内容进度，不以产品目标冒充现有库存。
- 学习事件能驱动字卡状态和复习建议；熟悉状态遵守跨日期、跨玩法的可解释条件，并可在家长区查看定义。
- 本机数据刷新后仍可读取；导出文件可校验且包含版本信息；存储失败、空数据和导入不兼容都有可理解的状态说明。
- 平板、手机和桌面布局均可操作；键盘、读屏、静音、减少动态效果和放大阅读有明确支持路径。
- 内容未具备真实录音或审校笔顺资料时，相应玩法不会伪装成已完成，不产生假正确结果。
