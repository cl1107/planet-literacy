# 学前识字依据

结论：教育部《3—6岁儿童学习与发展指南》对5—6岁儿童提出的是对图书、生活情境中的文字符号感兴趣并理解其用途，以及阅读理解、表达等发展目标；**没有规定幼儿园必学汉字表或统一识字数量**。因此，产品可以扩充可选字库，但不能将“600字”称作教育部标准、入学门槛或每个5岁孩子必须完成的目标。

## 官方依据

- [教育部《3—6岁儿童学习与发展指南》原文 PDF](https://www.moe.gov.cn/jyb_xwfb/xw_zt/moe_357/jyzt_2015nztzl/xueqianjiaoyu/yaowen/202104/W020210820338905908083.pdf)：“对图书和生活情境中的文字符号感兴趣，知道文字符号表示一定的意义。”这是5—6岁“喜欢听故事，看图书”目标的一项；同节还建议结合生活实际体会文字符号的用途。4—5岁目标涉及对生活中常见标识、符号的兴趣。其“阅读理解”目标强调讲述内容、根据画面推测故事、表达看法；“书面表达”目标包含用图画和符号表达、书写自己的名字。该文件按年龄段描述发展方向，并未列出应认的具体汉字或数量。
- [教育部学前教育专家指导委员会负责人答记者问](https://www.moe.gov.cn/jyb_xwfb/s271/201210/t20121015_143257.html)明确说：“反对通过机械记忆和强化训练过早识字。”其解释同时鼓励在生活情境和阅读活动中萌发文字兴趣。
- [《中华人民共和国学前教育法》第五十九条](https://hudong.moe.gov.cn/jyb_sjzl/sjzl_zcfg/zcfg_jyfl/202411/t20241108_1161363.html)规定：“幼儿园不得采用小学化的教育方式，不得教授小学阶段的课程”。教育部[2018年专项治理通知](https://hudong.moe.gov.cn/srcsite/A06/s3327/201807/t20180713_342997.html)也明确禁止幼儿园提前教授小学课程中的识字内容。上述边界针对小学化课程与教学方式，不等于禁止儿童在生活和阅读中自然接触汉字。

## 对字库与玩法的执行建议

1. 将约600个常见字定义为**产品可选素材池**，按孩子兴趣、理解情况逐步开放；3级是产品内部体验难度，不能对应官方年龄达标线。不要展示“幼儿园必须认识600字”“5岁应会600字”等文案，也不要以识字数给孩子排名或判断入学准备程度。
2. 先选能在儿童生活、图画书和游戏中自然解释用途的字：本人及家人称谓、身体与动作、家与学校、常见物品、自然和动物、位置方向、情绪与安全提示等。优先能配图、实物、场景和短句的字；具体频率表只能作为辅助筛选，不能把成人语料的高频字自动当作学前必学字。
3. 每张卡片提供图像或场景、读音、口语用法和亲子讨论入口；活动以观察、听故事、找标识、说话、角色游戏为主。允许跳过、重复和自由选主题；避免限时测验、机械闪卡、抄写打卡及强制解锁。
4. 对一字多音、抽象义、脱离儿童经验难以解释或只能靠字形记忆的字，提高引入门槛；若纳入字库，先给明确场景和正确读音。页面可呈现“认识过的字”作为个人探索记录，不能把点击或单次答对直接等同于稳定识字能力。

资料局限：上述国家层面文件提供发展目标和教育方式边界，**不提供可直接导入的幼儿园汉字清单**。约600字的规模、分级和主题分配均是产品设计决定，需要以后用儿童实际使用反馈和内容审校验证；小学阶段的课程字表不能直接改名为学前必学字表。
