# 初始化验收

验收日期：2026-10-04。范围为完整功能方案与可运行的项目骨架，不包含正式教学游戏和学习记录。

## 工程

`npm install` 成功，无依赖漏洞提示；`npm run build` 成功，包含 TypeScript 严格类型检查与 Vite 生产构建。
`npm ls --depth=0` 确认 React / React DOM 19.3.0、TypeScript 7.0.2 与 Adobe React Spectrum 3.47.5 实际安装。

## 可重复的浏览器检查

1. `npm run dev` 后打开终端显示的地址；太阳主题默认显示“日”，上一个字按钮禁用。
2. 点击下一个字：依次显示“光”“天”；最后按钮显示“再看一遍”，点击回到“日”。
3. 切换月亮主题，显示“月”，浏览位置回到第 1 / 3 个字。
4. 关闭声音，朗读按钮禁用；开启声音，朗读按钮可操作。
5. 进入汉字宇宙，存在 18 个示例条目；点击银河的“河”，回到对应主题第 3 个字。
6. 在家长页关闭拼音，回到识字页不显示拼音；再次打开恢复。
7. 未实施的词语、写字、字卡、足迹页面显示具体规划说明和返回识字的入口。

以上前六项已通过自动浏览器交互验证。首页分别以 1280×900、1024×768、390×844 检查并截图；页面无全局横向溢出，汉字与主要操作没有重叠。手机导航可横向滚动，页面内容可纵向滚动。

## 限制

无法通过页面状态验证孩子实际听到的设备音频质量，仍需目标平板试听。朗读错误会显示可读提示；语音依赖系统中文语音。字体使用在线加载并提供系统回退。
当前不保存偏好或学习成绩，刷新后恢复默认；掌握判断、复习、真实教学插画、录音与笔顺将在后续阶段实现。
